# Life in Weeks

A personal life visualization tool — your entire life as a grid of 52 weeks per row.

## Features

- **Grid view** — every week of your life at a glance, colored by phase, with event and log markers
- **Timeline view** — chronological list of all events and notes, grouped by life phase
- **Life phases** — color-coded bands (childhood, adolescence, etc.) you define
- **Events** — milestone markers that appear as corner triangles on grid cells
- **Notes / journal** — date-level log entries; click any week to journal in place
- **Mood / intensity** — rate each note 1–5 (rough → great); past weeks tint to match
- **Tags** — tag notes with `#travel`, `#health`, etc.; filter by tag in Timeline and Log views
- **Search** — ⌘K to search across all events and notes instantly
- **Export / Import** — copy/paste JSON to back up or transfer your data (birthdate excluded for privacy)
- **Dark & light theme** — system-aware with manual toggle
- **Life expectancy** — click any year label on the grid to set it

## Usage

Open `index.html` in any modern browser. All data is stored in `localStorage` — nothing leaves your device.

No build step, no dependencies, no server required.
